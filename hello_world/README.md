# C - Hello, World

This project introduces C programming and compilation.

The `0-preprocessor` script runs a C source file through the preprocessor and saves the result in a file named `c`.

The `1-compiler` script compiles a C source file into an object file (`.o`) without linking.

The `2-assembler` script generates assembly code from a C source file and saves it in a `.s` file.

The `3-name` script compiles a C source file into an executable named `cisfun`.

The `4-puts.c` program prints the specified text using `puts()`, followed by a newline.
