# C - Variables, if, else, while

This project introduces variables, conditional statements, and loops in C.

## Task 0: Positive anything is better than negative nothing

`0-positive_or_negative.c` prints whether a random integer is positive, negative, or zero.

## Task 1: The last digit

`1-last_digit.c` prints the last digit of a random integer and classifies it.

## Task 2: Alphabet

`2-print_alphabet.c` prints the lowercase alphabet.

## Task 3: alphABET

`3-print_alphabets.c` prints lowercase and uppercase alphabets.

## Task 4: Alphabet without e and q

`4-print_alphabt.c` prints the lowercase alphabet excluding e and q.

## Task 5: Numbers

`5-print_numbers.c` prints the digits 0 through 9.

## Task 6: Numberz

`6-print_numberz.c` prints digits 0 through 9 using only `putchar`.

## Task 7: Smile in the mirror

`7-print_tebahpla.c` prints the lowercase alphabet in reverse.

## Task 8: Hexadecimal

`8-print_base16.c` prints the hexadecimal digits 0 through f in lowercase.

## Task 9: Patience, Persistence

`9-print_comb.c` prints number combinations.
